# SpotiPars v2.2 — Экспорт и скачивание треков Spotify в MP3, FLAC, CSV и TXT

Полноценное настольное Windows-приложение в современном тёмном стиле для извлечения метаданных треков из буфера обмена (Ctrl+A ➔ Ctrl+C в Spotify) и автоматического скачивания аудиофайлов с обложками и ID3-тегами без использования платных API ключей.

![Icon](assets/icon.png)

---

## 🚀 Основные возможности

- **Вставка в 1 клик:** Кнопка «Вставить треки из буфера обмена» мгновенно парсит ссылки вида `https://open.spotify.com/track/...`, `spotify:track:...` и `https://open.spotify.com/intl-.../track/...`.
- **Скачивание аудио (yt-dlp + FFmpeg):**
  - Поддержка форматов:
    - **MP3 (320 kbps)** — максимальная совместимость с автомобильными магнитолами, плеерами и смартфонами.
    - **FLAC (Lossless)** — оригинальное качество без сжатия.
  - **Многопоточность:** параллельная загрузка в 4 потока (`ThreadPoolExecutor`).
  - **Умная дедупликация:** треки, которые уже есть на диске, автоматически распознаются и пропускаются со статусом `Пропущен (уже скачан)` (даже при разной нумерации).
  - **Шаблоны имён файлов:**
    - `Исполнитель - Название` *(по умолчанию — без номеров)*
    - `001. Исполнитель - Название`
    - `001 - Исполнитель - Название`
  - **Отдельная папка для плейлиста:** чекбокс для автоматического создания изолированной подпапки при скачивании.
  - **Динамическая нумерация:** правильная сортировка для списков более 999 треков (`0001. ...`, `00001. ...`).
  - Очистка имён файлов от недопустимых символов Windows (`\ / : * ? " < > |`).
- **Вшивка тегов и обложек (mutagen):**
  - Скачивание оригинальной обложки альбома в высоком разрешении.
  - Вшивание метаданных: Title, Artist, Album, Track Number, а также обложки в JPEG (ID3v2.3 APIC для MP3, Picture для FLAC).
- **Внутрисессионный журнал ошибок в RAM:**
  - Кнопка `📄 Журнал ошибок` в шапке окна. Все сведения о сбоях хранятся исключительно в оперативной памяти и очищаются при закрытии программы.
- **Экспорт таблицы:**
  - **CSV (Excel Ready):** Кодировка `UTF-8-SIG` (BOM) с разделителем `;` — открывается в Microsoft Excel двойным кликом без иероглифов.
  - **TXT:** Чистый список `Исполнитель - Название` с нумерацией.
  - **Буфер обмена:** Мгновенное копирование всего списка текстом.
- **Интерфейс CustomTkinter:**
  - Тёмная тема в стиле Spotify (`#121212`, `#181818`, зеленые акценты `#1DB954`).
  - Горизонтальный и вертикальный слайдеры (скроллбары) таблицы — никакой обрезки текста.
  - Отображение живого статуса каждого трека в таблице в реальном времени.

## 🛠 Запуск из исходников

```bash
# Клонирование репозитория
git clone https://github.com/Vbif228/SpotiPars.git
cd spotipars

# Создание и активация виртуального окружения
python -m venv .venv
.\.venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python main.py
```

## 🧪 Запуск тестов

```bash
python -m unittest discover -s tests -p "test_*.py"
```

## 📦 Сборка автономного .exe

Приложение собирается в единый `.exe` со встроенными `FFmpeg`, `yt-dlp` и ресурсами:

```bash
pyinstaller --noconsole --onefile --clean \
  --collect-all customtkinter \
  --collect-all yt_dlp \
  --collect-all mutagen \
  --add-data "assets;assets" \
  --add-binary "bin/ffmpeg.exe;." \
  --add-binary "bin/ffprobe.exe;." \
  --icon assets/icon.ico \
  --name SpotiPars main.py
```
